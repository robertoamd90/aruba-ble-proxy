# Aruba BLE Proxy 1.2.1

This maintenance release makes installation and updates through HACS easier to follow and brings the documentation up to date with 1.2.0. BLE forwarding and GATT runtime behavior are unchanged.

## HACS

- Add repository metadata in `hacs.json` and complete the integration manifest with an issue tracker and correctly formatted code owner.
- Add automated HACS repository validation on pushes and pull requests.
- Document installation as a HACS custom repository and migration from a manual installation. This does not imply inclusion in the HACS default catalog.

## Documentation

- Reorganize the README around requirements, installation, Aruba configuration, expected behavior and troubleshooting.
- Explain telemetry-based AP discovery, startup restoration, hardware model fallback and the distinction between scanner visibility and BLE device traffic.
- Refresh manual update instructions and the field-test checklist; label early Aruba setup experiments as historical notes.
- Clarify the scope of hardware compatibility reports without claiming additional tested combinations.

## Installing or updating

In HACS, open **Custom repositories**, add `https://github.com/robertoamd90/aruba-ble-proxy` with type **Integration**, and download **Aruba BLE Proxy**. Restart Home Assistant afterward. Existing users can retain their integration entries and Aruba transport configuration.

The automated Python suite passes **227 tests**. Interactive HACS installation and upgrade on a live Home Assistant instance have not been verified as part of this release.
